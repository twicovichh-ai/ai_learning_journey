# AI Coding Mentor for Kids

Это мой пет-проект — ИИ-ментор, который помогает детям изучать программирование. Я сделал его, чтобы попрактиковаться в Python и работе с API нейросетей.

### Что проект умеет:
* **ИИ-общение:** Модель объясняет основы программирования через примеры из игр (Minecraft, Roblox).
* **Контекстная память:** Система «помнит» прошлые вопросы, поэтому можно вести полноценный диалог, а не просто получать ответы на разовые вопросы.
* **Гибкость:** Умеет подстраиваться под уровень пользователя.

### Как запустить у себя:
1. Клонируй репозиторий.
2. Установи библиотеки: `pip install -r requirements.txt`
3. Создай файл `.env` и добавь туда свой ключ API: `API_KEY=твой_ключи_здесь`
4. Запусти скрипт: `python smart_tutor.py`
